# 🎮 osu! PP Comparison — for the fellas

A simple but clean way to compare osu! players stats — built for me and my two friends, because yeah… we always gotta know who's better.

---

## 🧠 What is this?

This is a small web app that lets you compare up to **3 osu! players** in real time.

It shows:

* PP (Performance Points)
* Accuracy
* Playcount
* Playtime
* Global & Country Rank

All in a clean UI with a bit of style.

---

## 👥 Why I made this

I made this thinking about my friends — we’re three, and we’re always comparing stats, arguing, and joking around about who’s ahead.

So instead of checking profiles one by one…
I just built this.

## ✨ Features

* Compare up to 3 players
* Multi-language (ES / EN / DE)
* Real-time fetch from osu! API
* Error handling for invalid players
* Ranking highlight (leader detection)
* Auto-refresh
